# LOCKER

Navy hackathon front end: React + Vite + TypeScript + Tailwind, React Flow + dagre,
Recharts, Framer Motion. Runs fully offline against mock JSON in `src/mock`, served
through `src/api/api.ts` (the only data entry point).

- Dev: `npm run dev` (http://localhost:5173). Build: `npm run build`.
- `npm run check:engine` prints the demo storyline odds; after 4 events TIDEWATCH must
  be 41% At risk with the TR Module as next domino, and ~84% after the top two fixes.
- Dev URL params: `?events=N` pre-applies N demo events, `?open=<nodeId>` opens a detail panel.
